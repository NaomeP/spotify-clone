# 🎧 Spotify Clone

A simple and interactive Spotify clone built using HTML, CSS, and JavaScript.

## 🚀 Features
- Play and pause songs
- Display current track
- Multiple songs support
- Clean and simple UI

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 📂 Project Structure
- index.html
- style.css
- script.js
- songs & images

## 🎯 How to Run
1. Download the project
2. Open index.html in your browser

## 💡 About
This project is created for learning and practice purposes to understand web development basics.
